# Filozofia interfejsu

Desktop First

AquaCore UI projektowany jest przede wszystkim dla komputerów PC.

Wersje:

- Desktop
- Tablet
- Mobile
- AquaCore Home

Wszystkie wersje posiadają te same funkcje.

Różnice dotyczą wyłącznie sposobu prezentacji danych.

Dashboard jest konfigurowalny.

Użytkownik może:

- zmieniać położenie widgetów
- zmieniać rozmiar widgetów
- dodawać nowe widgety
- usuwać niepotrzebne widgety

NAIDA zna strukturę AquaCore UI.

NAIDA nie zna układu pulpitu użytkownika.

NAIDA pomaga użytkownikowi odnaleźć funkcje systemu.

Konto Demo

Funkcje:

- automatyczne logowanie
- symulowane urządzenia
- przykładowe dane
- przykładowe alarmy
- przykładowe ekosystemy

Ograniczenia:

- brak SOS
- brak pomocy zdalnej
- brak AquaCore Monitor
- brak Recovery
- brak zmian globalnych

Przeznaczenie:

- prezentacja systemu
- nauka obsługi
- testowanie funkcji

Tryb tymczasowy:

Konto Demo nie przechowuje danych użytkownika.

Po wylogowaniu lub zakończeniu sesji:

- resetowane są ustawienia
- usuwane są zmiany Dashboardu
- usuwane są rozmowy z NAIDĄ
- usuwane są notatki
- usuwane są multimedia
- usuwane są historia i alarmy utworzone podczas sesji
- przywracane są domyślne ustawienia konta Demo

Każda nowa sesja rozpoczyna się od stanu początkowego.

Bezpieczeństwo:

Konto Demo jest współdzielonym środowiskiem demonstracyjnym.

Nie należy przechowywać w nim prywatnych danych.

Wszystkie dane sesji mają charakter tymczasowy.

Informacja dla użytkownika:

Korzystasz obecnie z konta Demo.

Zmiany dokonane podczas sesji nie są zapisywane.

Po wylogowaniu lub zakończeniu sesji konto zostanie automatycznie przywrócone do ustawień domyślnych.

Rozmowy z NAIDĄ, ustawienia oraz dane utworzone podczas sesji mają charakter tymczasowy.

Automatyczny reset:

Reset wykonywany jest:

- po wylogowaniu użytkownika
- po zamknięciu sesji
- po określonym czasie bezczynności

Przywracane są:

- układ Dashboardu
- ustawienia
- alarmy
- multimedia
- notatki
- rozmowy z NAIDĄ
- historia zdarzeń
- przykładowe dane

Każda nowa sesja rozpoczyna się od stanu początkowego.

NAIDA Demo:

NAIDA informuje użytkownika o pracy w trybie demonstracyjnym.

Przykładowy komunikat:

😊 Korzystasz z konta demonstracyjnego Smart Bio System.

Możesz swobodnie testować funkcje AquaCore.

Pamiętaj jednak, że po zakończeniu sesji wszystkie zmiany, rozmowy oraz ustawienia zostaną automatycznie usunięte.
